# 拾光 💕

> 两个人的私密情感空间:记录日常点滴、倒数重要日子、把日子过成糖。

一款面向情侣的本地纪念 App —— 用奶油手账风界面,收藏两个人之间的每一件小事。

## ✨ 功能一览

- **今天**:在一起天数(数字滚动 + 心跳)、每日情话、下一个纪念日进度环倒计时、那年今日、TA 的小宇宙每日一条、快捷记录入口
- **点滴**:时间轴 / 照片墙 / 日历三种视图,左右交错的奶油卡片依次浮现,支持照片 / 文字 / 地点 / 年份筛选
- **纪念日**:总天数大卡片 + 倒计时列表(进度环、重要等级、提前提醒),当天触发花瓣雨庆祝动画
- **我们**:情侣档案、愿望清单(完成点亮星星)、TA 的小宇宙、年度回顾、悄悄话信箱、应用锁、通知提醒
- **中央 + 悬浮按钮**:半屏快捷面板 —— 写一段话 / 拍一张 / 写情书 / 记心情 / 记地点 / 关于 TA
- **🎞️ 年度回顾**:电影式沉浸播放(四季章节、拍立得飘落、季节粒子、数据彩蛋、片尾纪念卡片可保存相册)
- **📮 悄悄话信箱**:定时解锁的信件(5 款信纸、火漆拆信动画、解锁通知)
- **🌌 TA 的小宇宙**:关于 TA 的分类备忘(自动分类推荐、卡片 3D 翻转、重要星级、搜索、自定义分类)
- **隐私**:PIN 应用锁、数据仅本地存储
- **温柔推送**:纪念日提醒、年度回顾预告、信件解锁、每周/每月恋爱备忘录

## 🛠 技术栈

| 类别 | 技术 |
|---|---|
| 语言 | Kotlin + Jetpack Compose (Material 3) |
| 架构 | 单 Activity + MVVM(StateFlow) |
| 存储 | Room(碎片 / 纪念日 / 愿望 / 信件 / 备忘)+ SharedPreferences |
| 图片 | Coil |
| 通知 | WorkManager 每日检查 |

minSdk 24 · targetSdk 36 · compileSdk 37

## 🚀 构建

1. 用 Android Studio 打开项目根目录
2. 同步 Gradle 后直接运行 `app` 模块
3. 首次启动即为干净空白状态(不含演示数据);在「我们 → 我的档案」填写情侣信息开始记录,「我们 → 初始化数据」可随时清空全部数据

## 📁 项目结构

```
app/src/main/java/com/example/fragments_of_life/
├── data/
│   ├── model/          # 数据模型(Moment / ImportantDate / WishItem / WhisperLetter / PartnerNote)
│   ├── local/          # Room 数据库、DAO、种子数据、情侣偏好
│   └── reminder/       # WorkManager 每日提醒
├── ui/
│   ├── components/     # 通用组件与动画(心跳、粒子、进度环、梦幻背景…)
│   ├── navigation/     # 4 Tab + 中央悬浮按钮导航
│   ├── screens/        # today / moments / anniversary / us / review / mailbox / universe …
│   ├── theme/          # 奶油手账配色(浅色 + 深色)
│   └── viewmodel/      # LifeViewModel
```
